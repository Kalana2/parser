# 🧠 Simple C Interpreter

A lightweight interpreter written in C that performs **lexical analysis, parsing, and execution** for a minimal custom programming language.

This project demonstrates core concepts of **compiler design**, including tokenization, recursive descent parsing, and symbol table management.

---

## 🚀 Features

- 🔍 Lexical Analysis (Tokenizer)
- 🌳 Recursive Descent Parser
- 🧮 Expression Evaluation (`+` operator)
- 📦 Variable Declaration (`int`)
- 🔄 Assignment Handling
- 🖨️ Print Statements
- ⚠️ Semantic Error Detection

---

## 📌 Supported Syntax

### Keywords
- `int`
- `print`

### Operators
- `=`
- `+`

### Symbols
- `(`
- `)`
- `;`
